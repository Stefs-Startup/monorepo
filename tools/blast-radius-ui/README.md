# `@cmp/blast-radius-ui` — Interactive Blast-Radius Graph Viewer

Local React Flow UI for inspecting `blast-radius-report.json` generated by `@cmp/blast-radius` with zero external SaaS calls.

## Usage

1. Generate a report from the repo root:
   ```bash
   pnpm blast-radius -- --base origin/main --out blast-radius-report.json --md-out blast-radius-report.md
   ```
2. Launch the local viewer:
   ```bash
   pnpm blast-ui -- --report blast-radius-report.json
   ```
3. Run workspace checks:
   ```bash
   pnpm --filter @cmp/blast-radius-ui run lint typecheck build test
   ```
