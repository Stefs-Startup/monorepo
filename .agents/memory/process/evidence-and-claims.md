# Evidence & Claims

1. **Tag every claim by epistemic status**:
   - **Verified**: directly observed via command/test output in this session; include the exact command/output or board post `#N` and date.
   - **Observed-by-user**: reported by the user during live usage; include timestamp/transcript reference and note if the root cause was not isolated.
   - **Hypothesis**: any untested explanation or inference.
2. **Never record hypotheses in `gotchas/` or `decisions/`**: Only verified observations and user-observed facts belong in persistent memory.
3. **Never write `"precisely because"` (or equivalent causal) inferences about third-party products as fact**: If you did not isolate and test the cause in code or a controlled experiment, state only what happened and mark the cause as not isolated.
4. **External sources require in-session URLs**: Any external article, vendor policy, or documentation cited must be fetched in-session and linked with its URL, or explicitly labeled `unsourced`.
